# Атлас непереводимых образов — сайт-лонгрид

Двуязычный (RU / EN) лонгрид по школьному проекту Валерии Бурховецкой (10 «А», МАОУ ЛИТ, руководитель — Толстиков С. В.):
**«Атлас непереводимых образов: Франко-английское издание»** — французские заимствования в английском языке,
как они пришли, как адаптировались, «ложные друзья переводчика» и как правильно читать такие слова.

Аудитория: школьники 10–11 классов, изучающие второй иностранный язык. Тон — дружелюбный, живой, но точный.

## Исходные материалы
- `src/Lexis_Project_EN (1).docx` — описание проекта на английском (цель, задачи, методы, структура Атласа).
- `src/Бурховецкая_отчет по проекту.docx` — отчёт на русском (актуальность, план, источники).
- Прочитать: `textutil -convert txt -stdout "src/<file>.docx"`. **`src/` — только брифы, код сайта там не лежит.**

## Стек
- Astro 5, статическая сборка, `srcDir: ./web` (см. `astro.config.mjs`). Без UI-фреймворков, без Tailwind.
- Ванильный CSS (custom properties), инлайн SVG для инфографики, минимум клиентского JS (vanilla, `<script>` в компонентах).
- Маршруты: `/` — русский (по умолчанию), `/en/` — английский.
- Команды: `npm run dev`, `npm run build` (= `astro check` + build, должен проходить без ошибок), `npm run preview`.

## Архитектура
```
web/
  i18n/types.ts        контракт контента (SiteContent) — источник правды
  i18n/ru.ts, en.ts    весь текст сайта; одинаковая структура, разный язык
  layouts/Base.astro   <html>, шрифты, мета
  styles/global.css    дизайн-токены и базовые стили
  components/*.astro   секции лонгрида, каждая получает prop `c: SiteContent`
  components/viz/*     инфографика (Timeline, OriginsChart, Doublets, WordRoutes)
  components/LongRead.astro  порядок секций
  pages/index.astro, pages/en/index.astro
```
**Правило: никакого текста в компонентах.** Все строки — только в `ru.ts` / `en.ts`. Компоненты не знают язык.

## Владение файлами (параллельная работа)
| Трек | Агент | Ветка / worktree | Файлы |
|---|---|---|---|
| Контент | `content-author` | `feat/content` | `web/i18n/ru.ts`, `web/i18n/en.ts` |
| Вёрстка | `ui-builder` | `feat/ui` | `web/layouts/`, `web/styles/`, `web/components/*.astro` (кроме `LongRead.astro`), `public/` |
| Инфографика | `infographics` | `feat/viz` | `web/components/viz/` |
| Ревью | `reviewer` | `main` после мержа | только читает, пишет отчёт |

`types.ts`, `index.ts`, `LongRead.astro`, `pages/`, конфиги — меняет только оркестратор на `main`.
Если треку нужно изменить контракт — не правь `types.ts`, а опиши нужное изменение в финальном отчёте.

## Git
- `main` — интеграционная ветка. Worktrees лежат рядом: `../lera-project-ip.worktrees/<track>`.
- Коммиты маленькие, сообщения на английском в стиле `feat(ui): ...`, `content(ru): ...`.
- Перед мержем каждая ветка должна проходить `npm run build`.

## Дизайн
«Миленький современный лонгрид»: тёплая бумажная подложка (кремовый), тёмно-синие чернила,
акценты — приглушённые французский синий и красный (намёк на триколор, без кича).
Шрифты (Google Fonts, с кириллицей): заголовки — **Playfair Display**, текст — **Manrope**, IPA/код — **JetBrains Mono**.
Мягкие скругления, тонкие линии, много воздуха, ширина текста ~68ch, плавные появления при скролле
(уважать `prefers-reduced-motion`). Mobile-first, без горизонтального скролла на 360px.
Цвета групп происхождения — токены `--c-french`, `--c-latin`, `--c-germanic`, `--c-greek`, `--c-other`.

## Качество
- Лингвистические факты — проверяемые (этимология по OED / Etymonline / CNRTL, IPA по Cambridge).
  Не выдумывать даты и цифры; если не уверен — формулировать мягче.
- RU и EN — равноценные тексты, а не машинный перевод друг друга.
- Доступность: семантические теги, alt/aria для SVG, контраст AA, клавиатурная навигация для интерактива.
